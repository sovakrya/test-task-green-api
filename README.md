# test-task-green-api

Простой чат с использованием GREEN API для отправки и получения
текстовых сообщений в telegramm

## Стек

React 19 · TypeScript · Vite · React Router

## Подготовка

1. Создать инстанс в GREEN API — инструкция:
   https://green-api.com/telegram/docs/before-start/
2. В настройках инстанса включить «Получать уведомления о входящих
   сообщениях и файлах» — без этого приложение не получит входящие сообщения.
3. Зафиксировать `Id Instance` и `Api token Instance` из настроек инстанса.

## Запуск

bun install
bun run dev

## Использование

1. На первой странице ввести Id Instance, Api token Instance и
   номер телефона получателя.
2. Нажать «Создать чат» — приложение проверит аккаунт получателя
   и покажет его имя и аватар.
3. Отправлять сообщения в поле ввода. Входящие сообщения появляются
   автоматически (опрос уведомлений, лимит — 1000 символов).
